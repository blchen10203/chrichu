# Reachdle Game Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** All game logic with no UI: scoring, slider maths, round picking, the date-seeded Daily set, saved progress and the share text.

**Architecture:** Pure TypeScript modules in `web/lib/engine/` plus a small `web/lib/storage/`. Nothing here imports React or touches the DOM, except one function that fetches `localStorage` safely. Functions take their data (fighters, metrics, dates, storage) as arguments, so every rule is tested with Vitest.

**Tech Stack:** TypeScript 5, Vitest. No other new dependency.

**Spec:** `docs/superpowers/specs/2026-11-10-reachdle-design.md` (sections 6, 7.1, 7.2, 9, 10, 12).

This is plan 2 of 4. Plan 1 (data pipeline) is done. Plan 3 (screens) builds on this one.

## Global Constraints

- Work in `web/`. Run commands from `web/`. Commit directly to `main`.
- `web/AGENTS.md` says this Next.js version differs from what you know. This plan adds no Next.js code, but read `web/node_modules/next/dist/docs/01-app/02-guides/testing/vitest.md` before Task 1's setup.
- Engine code never imports React, `next/*`, or reads `window`, `document` or `Date.now()` directly. Dates arrive as `YYYY-MM-DD` strings; randomness arrives as a `() => number`.
- Import with the existing `@/` alias (`@/lib/engine/types`).
- Spec constants, verbatim: free zone 0.5 steps; zero-score distance 3 steps; a Daily set has 5 different metrics, at least one of them height or reach, and no fighter appears twice; share colours are green for 80 or more, yellow for 40 to 79, red below 40; storage key `reachdle:v1`.
- The data files are `web/data/fighters.json` (200 fighters) and `web/data/metrics.json` (10 metrics). Do not edit them.
- No Survival logic in this plan (damage, HP, timer). `penalty` is exported so the Survival plan can reuse it.

## Facts about the data

- A fighter's `metrics` holds a key only when they are eligible for that metric. Eligibility is `metricId in fighter.metrics`.
- `age` in the file is the age on build day and only marks eligibility. The real answer is computed from `dob` on the day of play.
- `dob` can be `null` (then the fighter has no `age` key).
- A log metric has `snap: null`. Its values snap to 2 significant figures. Today that is only `career_sig` (`min` 22.6566, `max` 5867.9579, `step` 0.1257).
- `min` and `max` are not multiples of `snap` (reach is 59.8 to 86.2 with snap 0.5).

## Review Focus

Each line is pinned by a test in the task named.

1. Two browsers given the same date and data must build the same Daily set, whatever order the JSON arrays are in. (Task 4)
2. A snapped or nudged value must never leave the slider range, at either end, on both scales. (Task 2)
3. Corrupt, wrong-shaped or blocked storage must give an empty state and never throw. (Task 5)
4. A missed day must reset the streak; playing the same day twice must not raise it. (Task 5)
5. A saved round that points at a fighter or metric no longer in the data must be detected and replaced. (Task 4)

### Task 2: Slider maths

**Files:**
- Create: `web/lib/engine/scale.ts`, `web/lib/engine/scale.test.ts`

**Interfaces:**
- Consumes: `Metric` (Task 1).
- Produces:
  - `snapValue(metric: Metric, raw: number): number`, the nearest allowed value.
  - `nudge(metric: Metric, value: number, direction: 1 | -1): number`, the next allowed value that way, or the same value at the end of the range.
  - `toFraction(metric: Metric, value: number): number`, position on the axis from 0 (at `min`) to 1 (at `max`).
  - `fromFraction(metric: Metric, t: number): number`, the allowed value nearest that position; `t` outside 0 to 1 is clamped.
  - `formatValue(metric: Metric, value: number): string`.

"Allowed values": for a linear metric, the multiples of `snap` inside `[min, max]`. For a log metric, the numbers with at most 2 significant figures inside `[min, max]`.

- [ ] **Step 3: Implement the five functions**

- Round away float noise before returning (`Number(x.toFixed(6))`), so `81.5` is exactly `81.5`.
- Linear range ends are `ceil(min / snap) * snap` and `floor(max / snap) * snap`.
- Log: 2 significant figures of `x` is `Number(x.toPrecision(2))`. The lowest allowed value is `min` rounded *up* to 2 figures, the highest is `max` rounded *down*. One nudge is one unit of the second significant figure of the value you are moving *from*, except when stepping down from a power of ten (1000 goes to 990).
- `formatValue`: decimals are the decimals of `snap` (0.5 and 0.1 give 1, 1 gives 0); a log metric shows a whole number with `toLocaleString("en-US")`. Suffix `" in"` for unit `in`, `"%"` for unit `%`, nothing for any other unit.

- [ ] **Step 3: Write `rng.ts` exactly as below**

The pinned numbers depend on this exact algorithm (a string hash feeding mulberry32).

```ts
// Same seed, same sequence, in every browser. Do not change: saved puzzles depend on it.
export function rng(seedText: string): () => number {
  let h = 1779033703 ^ seedText.length;
  for (let i = 0; i < seedText.length; i++) {
    h = Math.imul(h ^ seedText.charCodeAt(i), 3432918353);
    h = (h << 13) | (h >>> 19);
  }
  h = Math.imul(h ^ (h >>> 16), 2246822507);
  h = Math.imul(h ^ (h >>> 13), 3266489909);
  let a = (h ^= h >>> 16) >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

- [ ] **Step 4: Implement `rounds.ts`**

- Sort fighters and metrics by `id` before any random pick, so input order never matters.
- A fighter is eligible when `metricId in fighter.metrics`. A round is valid when the metric exists, both fighters exist and are eligible, and they differ.
- `dailySet` uses `rng(date)` and nothing else random. Pick the silhouette metric first (one of `height`, `reach` at random), then 4 more from the remaining metrics, then shuffle the 5. For each, pick `ref` then `target` from eligible fighters not yet used in the set. Throw an `Error` when there are fewer than 5 metrics, neither `height` nor `reach`, or too few fighters.
- `randomRound` draws the metric from all metrics except `avoidMetric`.
- `repairRounds`: if every round from index `played` on is valid, return `saved`. Otherwise keep the first `played` rounds and take the rest from `dailySet(date, ...)` at the same indexes. (A rebuilt round may repeat a fighter or metric from a played one. That is accepted: it needs a data refresh mid-puzzle.)
- `puzzleNumber` and `ageOn` work on the date strings with UTC arithmetic, so daylight-saving changes cannot shift a day.

  - Types `DayState = { rounds: Round[]; guesses: number[]; scores: number[]; done: boolean }` and `State = { daily: { days: Record<string, DayState>; streak: number; maxStreak: number; lastDone: string | null }; survival: { best: number; runs: number }; infinite: { rounds: number; totalScore: number } }`.
  - `STORAGE_KEY = "reachdle:v1"` (exists), `emptyState(): State`.
  - `browserStorage(): Storage | null`, the only function allowed to touch `window`.
  - `load(storage: Pick<Storage, "getItem"> | null): State`, `save(state: State, storage: Pick<Storage, "setItem"> | null): void`.
  - `startDay(state: State, date: string, rounds: Round[]): State`.
  - `recordGuess(state: State, date: string, guess: number, score: number): State`.
  - `recordInfinite(state: State, score: number): State`.
  - `currentStreak(state: State, today: string): number`.
  - `dailyStats(state: State): { played: number; average: number; best: number }` over finished days, by day total.

  The update functions return a new state and never change their argument.

```ts
import { describe, expect, it } from "vitest";
import {
  STORAGE_KEY, currentStreak, dailyStats, emptyState, load, recordGuess, recordInfinite, save, startDay,
} from "@/lib/storage";
import type { Round } from "@/lib/engine/types";

const rounds: Round[] = [1, 2, 3, 4, 5].map((i) => ({ metric: `m${i}`, ref: `a${i}`, target: `b${i}` }));
const fake = (value: string | null) => ({ getItem: () => value });
const playDay = (state = emptyState(), date: string, scores = [50, 50, 50, 50, 50]) =>
  scores.reduce((s, score) => recordGuess(s, date, 70, score), startDay(state, date, rounds));

describe("load and save", () => {
  it("round-trips", () => {
    let stored = "";
    const state = playDay(emptyState(), "2026-12-01");
    save(state, { setItem: (key, value) => { expect(key).toBe(STORAGE_KEY); stored = value; } });
    expect(load(fake(stored))).toEqual(state);
  });
  it.each([null, "", "not json", "null", "[]", '{"daily":5}', '{"daily":{"days":[]}}'])(
    "gives an empty state for %s", (value) => {
      expect(load(fake(value))).toEqual(emptyState());
    });
  it("gives an empty state when storage is missing or throws", () => {
    expect(load(null)).toEqual(emptyState());
    expect(load({ getItem: () => { throw new Error("blocked"); } })).toEqual(emptyState());
  });
  it("does not throw when saving fails", () => {
    expect(() => save(emptyState(), { setItem: () => { throw new Error("full"); } })).not.toThrow();
    expect(() => save(emptyState(), null)).not.toThrow();
  });
});

describe("daily progress", () => {
  it("starts a day once and keeps its rounds", () => {
    const started = startDay(emptyState(), "2026-12-01", rounds);
    expect(started.daily.days["2026-12-01"]).toEqual({ rounds, guesses: [], scores: [], done: false });
    expect(startDay(recordGuess(started, "2026-12-01", 81, 50), "2026-12-01", [])).toEqual(
      recordGuess(started, "2026-12-01", 81, 50));
  });
  it("records each guess and finishes on the fifth", () => {
    const four = playDay(emptyState(), "2026-12-01", [10, 20, 30, 40]);
    expect(four.daily.days["2026-12-01"].done).toBe(false);
    expect(four.daily.streak).toBe(0);
    const five = recordGuess(four, "2026-12-01", 70, 50);
    expect(five.daily.days["2026-12-01"]).toMatchObject({ guesses: [70, 70, 70, 70, 70], scores: [10, 20, 30, 40, 50], done: true });
    expect(five.daily).toMatchObject({ streak: 1, maxStreak: 1, lastDone: "2026-12-01" });
  });
  it("ignores a guess on a finished or unstarted day", () => {
    const done = playDay(emptyState(), "2026-12-01");
    expect(recordGuess(done, "2026-12-01", 1, 100)).toEqual(done);
    expect(recordGuess(emptyState(), "2026-12-01", 1, 100)).toEqual(emptyState());
  });
  it("does not change the state it was given", () => {
    const before = startDay(emptyState(), "2026-12-01", rounds);
    const copy = structuredClone(before);
    recordGuess(before, "2026-12-01", 81, 50);
    expect(before).toEqual(copy);
  });
});

describe("streak", () => {
  it("grows on consecutive days, across a month end", () => {
    const s = playDay(playDay(playDay(emptyState(), "2026-12-30"), "2026-12-31"), "2027-01-01");
    expect(s.daily).toMatchObject({ streak: 3, maxStreak: 3, lastDone: "2027-01-01" });
  });
  it("resets after a missed day but keeps the record", () => {
    const s = playDay(playDay(playDay(emptyState(), "2026-12-01"), "2026-12-02"), "2026-12-04");
    expect(s.daily).toMatchObject({ streak: 1, maxStreak: 2 });
  });
  it("shows zero once a day has been missed", () => {
    const s = playDay(emptyState(), "2026-12-01");
    expect(currentStreak(s, "2026-12-01")).toBe(1);
    expect(currentStreak(s, "2026-12-02")).toBe(1); // today not played yet
    expect(currentStreak(s, "2026-12-03")).toBe(0);
    expect(currentStreak(emptyState(), "2026-12-01")).toBe(0);
  });
});

describe("stats", () => {
  it("averages and finds the best finished day", () => {
    let s = playDay(emptyState(), "2026-12-01", [100, 100, 100, 100, 41]);
    s = playDay(s, "2026-12-02", [60, 60, 60, 60, 60]);
    s = recordGuess(startDay(s, "2026-12-03", rounds), "2026-12-03", 1, 100); // unfinished
    expect(dailyStats(s)).toEqual({ played: 2, average: 371, best: 441 });
    expect(dailyStats(emptyState())).toEqual({ played: 0, average: 0, best: 0 });
  });
  it("totals Infinite rounds", () => {
    expect(recordInfinite(recordInfinite(emptyState(), 80), 40).infinite).toEqual({ rounds: 2, totalScore: 120 });
  });
});
```

- [ ] **Step 3: Implement `web/lib/storage/index.ts`**

- `load` returns `emptyState()` unless the stored text parses to an object whose `daily.days` is a plain object (not an array), `daily.streak` and `daily.maxStreak` are numbers, and `survival` and `infinite` are objects. Catch every error.
- `browserStorage` returns `window.localStorage`, or `null` if `window` is undefined or reading the property throws.
- `startDay` does nothing when the day already exists. `recordGuess` does nothing when the day is not started or is already done.
- On the fifth guess of a day: `done` becomes true; `streak` is the old streak plus 1 when `lastDone` is the day before `date`, else 1; `maxStreak` is the larger of itself and `streak`; `lastDone` is `date`.
- `currentStreak` is `streak` when `lastDone` is `today` or the day before `today`, else 0.
- `dailyStats.average` is rounded to a whole number.
- "The day before" uses UTC arithmetic on the date strings.
